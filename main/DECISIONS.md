# Decisions & Assumptions

Deviations from, or unspecified choices left to, [docs/README.md](../docs/README.md).

- **Project layout:** the Next.js app lives in `main/` (a subfolder of the repo root), with `docs/` next to it holding the spec. All paths in the README/task plan that assume the app is at the repo root (e.g. `src/`, `prisma/`) are relative to `main/` instead.
- **Postgres host port:** mapped to `5433` on the host in `docker-compose.yml` (container still listens on `5432` internally) to avoid colliding with a local Postgres instance already using the default port.
- **Prisma pinned to 6.19.3 (exact):** Prisma 7 removed the classic `datasource { url = env("DATABASE_URL") }` schema pattern in favor of a `prisma.config.ts` file plus a driver adapter (e.g. `@prisma/adapter-pg`). That's extra setup the README doesn't anticipate, so we pinned `prisma` and `@prisma/client` to the last stable 6.x release (`6.19.3`, exact version to avoid drifting to 7/8 on a future install) and kept the simple schema-based config.
- **Design tokens taken from literals, not CSS variables:** the prototype (`docs/design-reference/Sprint Planner.dc.html`) defines colors/sizes as inline literals rather than `:root` custom properties. `docs/design-reference/TOKENS.md` was built by grepping those literals (plus the `PB` priority-badge config object) and cross-checking against the 31 reference screenshots, then mapped into Tailwind's `@theme` in `main/src/app/globals.css`.
- **Priority badge colors:** DESIGN.md only says "gray / amber / red"; the prototype defines exact hexes (low `#F1F5F9`/`#334155`/`#64748B` dot, medium `#FEF3C7`/`#92400E`/`#D97706` dot, high `#FEE2E2`/`#991B1B`/`#DC2626` dot). Per the instruction that the prototype wins on visual details, these exact values were used.
- **No web font:** the prototype loads no web font and uses the system font stack (`-apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, Ubuntu, "Helvetica Neue", sans-serif`). DESIGN.md allows Inter as an option but defaults to system fonts; since the prototype (visual authority) uses system fonts, the default Next.js Geist font loading was removed from `layout.tsx` to match.
- **Dark mode:** not implemented. DESIGN.md marks dark mode optional/"support light mode first" and it's out of scope for design (section 10); the prototype itself is light-only. `globals.css` defines a single light palette instead of a light/dark pair.
